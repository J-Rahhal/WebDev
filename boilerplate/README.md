# Boilerplate

## DOCTYPE

```html
<!DOCTYPE html>
```

this line, tells the browser what version of html we are using

## html tag

This is called the root element. it surrounds all the content of the webpage `lang='en'` specifies the language of the page.

## head tag

The head section contains important meta data, or instruction for the browser.

| Element   | What it does                                                                    |
| --------- | ------------------------------------------------------------------------------- |
| `<title>` | Sets the title shown in the browser tab                                         |
| `<meta>`  | Provides information about the page, such as character encoding and description |
| `<link>`  | Connects external resources, commonly CSS files                                 |
| `<style>` | Contains CSS directly inside the HTML                                           |
| `<body>`  | Contains all the content of the page                                            |

> `<meta charset="UTF-8">` is a standardized character encoding widely used on the webpage. it is a method used by computers to store characters as data. By setting the character encoding to `UTF-8`, it ensures special characters are displayed such as `e` or `a` with accents.
